Privacy

Privacy

Short version: the app keeps everything on your phone, and this website sets no cookies.

The app

TapTL captures your screen only while translating is on, and only after you tap "Share screen". Frames are read on the phone by ML Kit and thrown away. They are never saved or uploaded.

  • No account, no sign-in and no server of ours.
  • No analytics or crash reporting in the app.
  • The internet is used once per language, to download Google's on-device translator through ML Kit. After that it works offline.
  • Translations are cached on the phone so the same words don't need translating twice. Clearing the app's data removes them.

This website

This site is plain static pages. It sets no cookies, has no trackers and loads no third-party scripts or fonts. Your theme choice is kept in your own browser's storage.

It's served by Cloudflare, which, like any host, handles the network requests that reach it. Downloads come from GitHub Releases, under GitHub's own privacy terms.

Questions

Open an issue on GitHub. The code is all there too, so you can check any of this yourself.

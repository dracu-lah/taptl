How it works

Five steps, all on the phone.

  1. Screen capture

    Android's own screen sharing, at half size. Nothing leaves the phone.

  2. Only what changed

    Each frame is checked against the last. No change, no work.

  3. Read the text

    ML Kit reads only the changed parts, in your chosen language.

  4. Translate

    Game word list, then cache, then on-device Google Translate.

  5. Draw

    One see-through layer puts colour-matched English over the text.

Never uses: Accessibility service Fake taps Reading game memory Root

Install

Set up in about a minute.

Get started

  1. Download app-release.apk and open it. Allow "install unknown apps" if asked.

  2. Open TapTL, pick your language, then finish the home screen list:

    • Show over other apps, to draw on top.
    • Notifications, for the Stop button.
    • Language pack, about 40 MB, once.

  3. Optional: add the Translate tile when offered, or drag it in from Quick Settings.

  4. Tap Start, open your game and tap Share screen. English shows in about half a second.

Questions

Good to know.

Which games does it work with?

Any app or game that allows screen capture. It was built and tuned on Valorant Mobile CN (无畏契约 源能行动), so that game gets the best results.

Does it need internet?

Only once per language, to download the translator. After that it works fully offline.

Is it safe with anti-cheat?

TapTL only looks at the screen, like a screen recorder, and draws on top. It doesn't touch the game, its memory or your taps. Still, there's no guarantee: a game's anti-cheat can decide what it likes. Test on a secondary account first.

Does it translate during a match?

No. It hides during gameplay so it never covers what you need to see. It's for menus, settings, the store and popups.

Why does Android ask to share my screen every time?

That's an Android rule on Android 14 and newer. Apps can't skip it.

Why do I have to add the tile myself?

Android requires you to confirm any Quick Settings tile. On Android 13 and newer, TapTL asks with one tap. On older versions, swipe down twice, tap the pencil and drag "Translate" in.

Can it translate into a language other than English?

Not yet. Everything goes to English.

Is it really free?

Yes. It's open source under the MIT license, with no ads and no paid tier. If it helps you, you can chip in, but nothing is locked behind it.

Known limits

  • Menus only. No in-match chat.
  • Android 14+ asks to share the screen each time.
  • Apps that block capture can't be read.
  • Machine translation can be wrong or clumsy.
  • English output only. Word list is Valorant CN only.
  • 64-bit ARM phones (almost all recent ones).
